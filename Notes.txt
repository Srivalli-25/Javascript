What is a variable in JavaScript?
A variable is a named container used to store a value in JavaScript.


What are the three keywords used to create variables?
Var, let, const are the three variables required.


Write the syntax to create a variable using var.

Write the syntax to create a variable using let.

Write the syntax to create a variable using const.

What is declaration?
Declaration means creating a varible by giving it a name.


What is initialization?
Initialization means assigning a value to a varaible.


What is reassignment?
Reassignment means changing the value of an existing varaible.


What is redeclaration?
Redeclaration means declaring the same varaible again using the same keyword.


Which keyword allows redeclaration?
var allows redeclaration.


Which keyword allows reassignment?
var and let allows reassignment.


Which keyword requires initialization when declared?
const keyword requires initialization when declared.

What is the difference between let and const?
A let varaible can be reassigned, but a const varaible cannot be reassigned.


What is the difference between var and const?
